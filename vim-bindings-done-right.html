Vim bindings done right

2026-03-07

Most apps that claim "Vim support" give you hjkl and call it a day. Glifo takes it further — a full space-leader system that makes every action accessible from normal mode.

The space-leader system

In Vim, the leader key is a namespace for custom commands. Glifo uses Space as the leader, which means every app action is two keystrokes away:

SequenceAction
Space IEnter insert mode
Space ZToggle zen mode
Space BToggle sidebar
Space SToggle split view
Space EToggle preview
Space FFocus sidebar search
Space WSave note
Space NNew note
Space UUndo
Space RRedo
Space YCopy as HTML
Space QClose current note
Space /Search within note

This means you can create a note (Space N), write in insert mode, switch to split view (Space S), save (Space W), and close (Space Q) — all without touching the mouse.

Standard shortcuts

For non-Vim users, everything works with standard macOS shortcuts:

ShortcutAction
Cmd+NNew note
Cmd+SSave
Cmd+,Settings
Cmd+BToggle sidebar
Cmd+WClose note
Cmd+ZUndo
Cmd+Shift+ZRedo

Search operators

The sidebar search builds structured filter chips from typed shortcuts:

InputCreates
#blogTag filter
-#draftExclude tag
/ProjectsFolder scope
modified:weekModified this week
is:untaggedNotes without tags
has:codeNotes with code blocks
type:drawingOnly drawings

Press Enter to commit a chip. Backspace on an empty input removes the last chip.

Slash menu

Type / at the start of a line to open the block inserter:

  • Heading 1, 2, 3
  • Bullet list, numbered list, task list
  • Code block, blockquote, table
  • Horizontal rule

No palette to memorize, no toolbar to hunt through. Type the trigger, pick the block, keep writing.
